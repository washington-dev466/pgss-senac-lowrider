## tipos de sistemas de informaçao;

* Sistemas de Processamento de Transações (SPT)
* Sistemas de Informação Gerencial (SIG)
* Sistemas de Suporte à Decisão (SSD)
* Sistemas de Informação Executiva (EIS)

* # O que é um Sistema de Informação

Um Sistema de Informação (SI) é um conjunto organizado de componentes que trabalham juntos para:

* Coletar dados
* Processar esses dados
* Armazenar informações
* Distribuir informações útei

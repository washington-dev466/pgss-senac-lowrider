# Sistemas de Informação - Conceito e Tipos

> Material educativo sobre os fundamentos de Sistemas de Informação (SI) e suas aplicações nas organizações.

## 📚 O que é um Sistema de Informação?

Um **Sistema de Informação (SI)** é um conjunto organizado de componentes integrados que trabalham em harmonia para:

- 📊 **Coletar** dados de diversas fontes
- ⚙️ **Processar** esses dados de forma estruturada
- 💾 **Armazenar** informações de forma segura e organizada
- 📤 **Distribuir** informações úteis aos usuários e stakeholders

Os Sistemas de Informação são fundamentais para o funcionamento das organizações modernas, facilitando a tomada de decisões estratégicas e a automação de processos.

---

## 🎯 Principais Categorias de Sistemas de Informação

### 1. **Sistemas de Processamento de Transações (SPT)**
- Automatizam operações rotineiras e repetitivas
- Exemplos: Folha de pagamento, Controle de estoque, Sistema de vendas
- Foco: Eficiência operacional

### 2. **Sistemas de Informação Gerencial (SIG)**
- Fornecem relatórios para gerentes tomarem decisões
- Exemplos: Dashboards, Relatórios de vendas, Análise de performance
- Foco: Apoio à gestão tática

### 3. **Sistemas de Suporte à Decisão (SSD)**
- Analisam dados complexos para auxiliar na tomada de decisão
- Exemplos: Simulações, Análise de cenários, Business Intelligence
- Foco: Decisões estratégicas

### 4. **Sistemas de Informação Executiva (EIS)**
- Oferecem visão geral e estratégica para executivos
- Exemplos: KPIs, Indicadores de desempenho, Executive dashboards
- Foco: Estratégia corporativa

---

## 🔄 Ciclo de Vida de um Sistema de Informação

```
Coleta de Dados → Processamento → Armazenamento → Distribuição → Utilização
```

1. **Entrada (Input)**: Coleta de dados brutos
2. **Processamento (Processing)**: Transformação em informações úteis
3. **Saída (Output)**: Relatórios e insights gerados
4. **Retroalimentação (Feedback)**: Avaliação e melhorias
